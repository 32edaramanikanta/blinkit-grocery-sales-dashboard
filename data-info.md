# Data Information

## Dataset
This project uses a grocery sales dataset analyzed in Power BI.

## Analysis Fields
The dashboard analyzes fields related to:
- Product category
- Product ID
- Sales
- MRP
- Outlet identifier
- Outlet location
- Outlet size
- Outlet type
- Outlet year
- Product visibility
- Fat content

## Analysis Performed
- Total sales analysis
- Average sales analysis
- Product-category performance
- Outlet performance
- Outlet-year trends
- Product visibility analysis
- Location and tier analysis
- Interactive filtering

## Tool
Power BI

> Note: The original dataset file is not included in this repository.
